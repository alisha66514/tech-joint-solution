# The Maharaja Perfumes — Fullscreen Hero / Black & Gold Edition

The supplied perfume video fills the full-screen hero (not the right-side card).
This edition retains the original page structure while restyling the full case study
with an obsidian black, deep charcoal, and champagne gold luxury palette.

**Run:** Extract this ZIP, open the folder in VS Code, and use Live Server on
`project-maharaja-perfumes.html` (recommended) or `maharaja-all-in-one.html`.
Keep `assets/` alongside the HTML files: the video and poster are local files.

- `css/maharaja-black-theme.css`: dark luxury theme (loaded after original CSS)
- `css/maharaja-hero-video.css`: full-screen cinematic video positioning
- `js/maharaja-hero-video.js`: hero video behavior
- `assets/videos/maharaja-woman-perfume-hero.mp4`: supplied perfume video
- `maharaja-all-in-one.html`: inline HTML/CSS/JS, with external video assets

The original blue agency site is not modified; this theme is scoped to this page.
Links to other pages in the navigation require the rest of the site to be deployed.
